:::caution[Pre-alpha]
The hardware is a routed first-article design and the library has no CAN transport bound to it
yet, so nothing here talks to a real device. No performance figure is claimed until it has been
measured and the method published alongside it.
:::

  <Card title="It tells you when it is wrong" icon="warning">

  </Card>
  <Card title="The protocol is published" icon="open-book">

    integrate a non-WPILib stack — no SAPPHIFY software required.
  </Card>
  <Card title="Nothing throws" icon="approve-check">

    status code, and every status code documents its remedy.
